# 🎴 三副牌升级 (Triple-Deck Shengji)

三副牌升级的 Web 可视化对局版本。162 张牌（3 副 × 54），人均 39 张手牌 + 6 张底牌，场上总分 300 分。支持完整的 **叫主反主 → 埋底炒底 → 出牌 → 结算** 流程，由机器人 AI 自动对局，前端 Canvas 动画逐步演示。

## ✨ 功能特性

- **三副牌完整牌型体系**：单张 / 对子 / 刻子 / 拖拉机 / 推土机 / 甩牌
- **叫主与反主**：级牌叫主，3 反 2、2 反 1；无人叫主打无主
- **埋底与炒底/反炒**：庄家埋 6 张，**四人逆时针多轮竞价炒底/反炒**（含庄家同伴），以主牌 2 张换 1 张 / 3 张换 2 张（优先级：3 大王 > 3 小王 > 3♠… > 2♦）；自己刚埋/刚换的底不能紧接着自己再动，须别人先动过才能回来反炒（庄家亦可反炒闲家埋的底）
- **出牌操作名显示**：毙牌 / 盖毙 / 甩牌 / 甩牌失败 / 毙甩牌 在出牌牌组下方实时标注
- **300 分制升级结算**：光头 +3 / 双升 +2 / 单升 +1 / 上台（不升级）/ 上台 +1~+3（封顶）
- **抠底翻倍**：单张 ×2、对子 ×4、刻子 ×8、拖拉机 / 推土机 ×2ⁿ
- **过 A 结算**：任一阵营越过 A 级即最终胜利
- **连打模式**：记录级牌与庄家，可续局

## 🚀 快速开始

### 环境要求

- Python 3.8+
- 现代浏览器（Chrome / Edge / Firefox）

### 安装与运行

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动服务
python app.py

# 3. 浏览器访问
#   → http://localhost:5000
```

常用参数：

```bash
python app.py --port 8080   # 指定端口
python app.py --no-debug    # 关闭调试模式
```

### 运行命令行模拟（可选）

`game.py` 附带 CLI 测试入口，可批量模拟对局用于验证规则：

```bash
python game.py --seed 1234        # 固定随机种子
python game.py --rounds 500       # 模拟 500 局上限
```

## 🎮 使用说明

| 操作 | 说明 |
| --- | --- |
| ▶ 开始 | 开始新对局（可输入随机种子复现同一局） |
| ▶ 下一步 | 手动逐圈推进：叫主 → 埋底 → 炒底 → 出牌（逐家亮牌） → 结算 |
| ▶▶ 自动 | 自动连续播放，点击 / 空格 暂停 |
| 🔄 重置 | 结束当前对局，重新开始 |
| 延迟 | 慢速 800ms / 中速 400ms / 快速 150ms / 极速 40ms |
| 种子 | 输入数字种子可复现完全相同的对局 |

### 界面布局

- **顶部**：对局信息（局数、级牌、主花色、庄家、队伍等级、闲家得分）
- **四侧**：四名玩家手牌（下/右/上/左）
- **中央**：出牌区 + 底牌区 + 叫主 / 炒底 / 结算信息
- **牌面标记**：⭐ 表示主牌；牌组下方红/黄/橙色标签表示毙牌 / 盖毙 / 甩牌等操作

## 🔌 后端 API

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/` | GET | 网页界面 |
| `/api/new` | POST | 创建新对局，参数 `{seed}` 可选 |
| `/api/step` | POST | 推进一个视觉步骤，参数 `{session_id}` |
| `/api/status` | GET | 获取当前快照，参数 `?session_id=` |
| `/api/reset` | POST | 销毁会话 |

## 📜 游戏规则速览

> 完整规则见本地文档 `2026.8.31-三副牌升级.md`（仅本地维护，不上传）。

- **牌数**：162 张，人均 39 张 + 6 张底牌，场上总分 300 分
- **主牌顺序**：大王 > 小王 > 级牌 > 2（常主）> 主花色牌
- **叫主**：本局级牌 ≥1 张即可叫，张数越高越大；同数量先叫者为大
- **炒底**：用主牌（大王/小王/级牌）2 张起炒，3 换 2、2 换 1，始终保持手牌 39 张、底牌 6 张
- **升级表**（300 分制）：

| 抓分方得分 | 结果 | 抓分方 | 庄家方 |
| --- | --- | --- | --- |
| 0 | 光头 | 0 | +3 |
| 5 ~ 55 | 双升 | 0 | +2 |
| 60 ~ 115 | 单升 | 0 | +1 |
| 120 ~ 124 | 上台 | 0 | 0 |
| 125 ~ 175 | 上台+1 | +1 | 0 |
| 180 ~ 235 | 上台+2 | +2 | 0 |
| 240 ~ 295 | 上台+3 | +3 | 0 |
| 300+ | 封顶 | +3 | 0 |

- **过 A**：等级循环 2→A，共 13 级；任一阵营过 A 即最终胜利

## 🛠️ 技术说明

- **后端**：Python / Flask，状态机 `idle → trump → bury → stir → playing → settled`
- **前端**：原生 HTML + Canvas 2D，无第三方框架
- **出牌**：机器人 AI（`Bot`）自动决策，逐家亮牌动画演示
